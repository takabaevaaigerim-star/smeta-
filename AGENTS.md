# Правила работы в проекте «Смета за 5 минут»

- Работать только в этой папке. Перед правкой читать текущие файлы.
- Делать только ту функцию, которую просит пользователь. Уже работающие части оставлять рабочими.
- Писать только обычные HTML, CSS и JavaScript. Без npm, фреймворков и внешних ресурсов.
- Данные пользователя остаются в браузере. Ничего не отправлять в интернет.
- Удобство: понятные подписи; поля и кнопки не меньше 44px; работа с клавиатуры и на телефоне.
- Деньги показывать с пробелами между тысячами: `15 000 ₸`. Пустые и неверные числа считать нулём. Никогда не показывать `NaN`.
- Git не запускать и ничего не публиковать, пока пользователь сам об этом не попросит.
- После работы перечислить изменённые файлы и как проверить результат.
